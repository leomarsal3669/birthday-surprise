HARINI — PREMIUM BIRTHDAY WEBSITE (VERSION 2)

HOW TO OPEN
1. Extract this ZIP.
2. Open the extracted folder.
3. Double-click index.html to preview in Chrome, or open the folder in VS Code.

ADD PHOTOS
Put your photos in assets/images using these exact filenames:
- harini-old-photo.jpg
- school-memory-1.jpg
- harini-current-photo.jpg
- letter-photo.jpg

You can add more photos later by editing the gallery in index.html.
If your photo is PNG, either rename it to the listed .jpg only if it really is a JPEG,
or change the filename in index.html to match the actual extension.

ADD MUSIC
Put an MP3 file at:
assets/music/birthday-song.mp3
The music starts only after the visitor clicks the envelope or Music button because
modern browsers block automatic audio playback. One audio player continues across sections.

IMPORTANT PERSONALIZATION
- The school-year timeline uses grade labels, not a guessed number of years.
- The story wording is intentionally respectful and does not pressure Harini.
- Review all personal photos and the handwritten letter before publishing.
- Anyone with the public website link may be able to view it. Do not upload anything
  private unless Harini is comfortable with it.

PUBLISH
You can deploy the complete extracted folder using Netlify Drop:
https://app.netlify.com/drop
Upload the project folder (or its contents as instructed by Netlify), then share the
generated public URL. Test the website on a phone before sharing.

This is a static frontend website. It has no login, private account, or secure password gate.
